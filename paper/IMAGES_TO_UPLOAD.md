## How to generate `dashboard.png`

Open two terminals at the repo root.

**Terminal 1 — start the live system (backend + sender):**

```cmd
run.bat
```

Wait until the dashboard is reachable at `http://localhost:5000/dashboard` (about 5 s).

**Terminal 2 — install Playwright once, then capture:**

```cmd
venv312\Scripts\python.exe -m pip install playwright
venv312\Scripts\python.exe -m playwright install chromium
venv312\Scripts\python.exe paper\scripts\screenshot_dashboard.py
```

The script writes `dashboard.png` (plus the unused `pred_normal.png` and `pred_abnormal.png`) into `paper/figures/`. Only `dashboard.png` is referenced by `main.tex`; upload that one to the Overleaf `figures/` folder.

## Final upload order on Overleaf

1. Create a new blank Overleaf project.
2. Upload `main.tex` and `references.bib` to the project root.
3. Create a `figures/` folder.
4. Upload `architecture.tex` and `deployment.tex` into `figures/`.
5. Upload the 2 PNGs (`confusion_matrix_hybrid.png`, `dashboard.png`) into `figures/`.
6. Set `main.tex` as the main document (Menu → Settings → Main document).
7. Compile with pdfLaTeX. If references show as `[?]`, click "Recompile from scratch" once.
